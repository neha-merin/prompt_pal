## 📌 Project Overview

PromptPal is a modern AI Assistant designed as a **Prompt Engineering** project. It demonstrates how carefully crafted prompts can guide AI systems to perform different tasks effectively.

The application allows users to:

- 💬 Answer factual questions
- 📝 Summarize long text
- ✨ Generate creative content
- 📖 Explore prompt templates
- ℹ️ Learn about the project through an About page
- ❓ Follow a built-in Help Guide
- 👍 Provide feedback on AI responses

## 🧠 AI Functions

### 💬 1. Answer Questions

Provides clear and beginner-friendly answers to user queries.

Example:

```
What is Artificial Intelligence?
```

---

### 📝 2. Summarize Text

Summarizes long text into concise bullet points.

Example:

```
Summarize the following article...
```

---

### ✨ 3. Creative Content

Generates creative writing such as:

- Stories
- Poems
- Essays
- Business Ideas

Example:

```
Write a short story about a dragon.
```
