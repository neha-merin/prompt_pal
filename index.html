About PromptPal

Overview of the application, objectives, and technology stack.

Project Information

Project Name: PromptPal – AI Assistant
Version: 1.0.0 (Production Ready)

Objective

This application demonstrates Prompt Engineering by allowing users to interact with an AI assistant capable of answering questions, summarizing text, and generating creative content using carefully designed system prompts.

Technologies Used

HTML5 CSS3 (Glassmorphism) JavaScript (ES6 Modules) AI API Engine Prompt Engineering

Help & User Guide

Follow these simple steps to get the best results from PromptPal.

1

Select Your Assistant Function

Choose from Answer Questions, Summarize Text, or Creative Content using the top dropdown menu or pill selectors.

2

Enter Your Prompt or Select a Preset

Type your custom prompt in the text box or click any of the pre-configured prompt chips below the input area.

3

Generate & Review AI Response

Click Generate Response (or press Ctrl + Enter). The AI applies the corresponding system prompt to craft a clear, structured response.

4

Copy Response & Provide Feedback

Use the Copy Response button to copy the output to your clipboard, and rate the response using the 👍 Helpful or 👎 Not Helpful buttons.
